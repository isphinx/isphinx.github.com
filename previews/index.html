主页方案存档

重做首页时并行探索的三个方向，内容都来自 resume/resume.md，全部单文件、无构建、无外部依赖（只有 Google Fonts）。最终上线的是方案 C，见 首页。A 和 B 留作存档。

方案 A

深色终端 / 代码编辑器

延续 resume-dev 的「职业即源码」概念，做成一个会开机自检的终端。开场自动敲 whoami → 名字放大浮现，底部提示符可以真的输入命令（help / skills / git log / contact / sudo）。工作经历是 git log 图谱，滚动时轨道逐段点亮。

方块光标 + 反色混合飘落字符雨鼠标光晕打字机开场标题乱码解码磁吸按钮可交互 shell
 方案 B

示波器 / 仪表盘

把「latency、throughput、reliability 就是产品本身」直接画出来。首屏是一台示波器：鼠标左右改频率、上下改幅度，点击注入一个瞬态冲击。工作经历是一条 2004→2026 的阶梯波形，鼠标悬停某段经历会在波形上落下测量光标。

十字准线 + 坐标读数鼠标驱动波形点击注入瞬态三通道荧光配色职业曲线联动经历可展开折叠实时 HUD
 方案 C · 已上线

游戏引擎调试视口

致敬 C++/Lua 游戏服务器出身。整页跑一个粒子线框球体，鼠标推开粒子、按住吸引、点击放冲击波。鼠标是旋转准星，悬停任何区块会画出引擎风格的调试包围盒和尺寸标注。工作经历做成场景树 + Inspector 面板。

粒子线框场 + 力场旋转准星光标调试包围盒真实 FPS 曲线点击冲击波名字 RGB 抖动场景树 Inspector

提示：三个方案都尊重 prefers-reduced-motion，触屏设备自动关闭自定义光标。方案 A/B/C 里的「下载简历」都指向 ../resume/resume.pdf。
